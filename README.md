# LEADMEET OS

Система привлечения собственников бизнеса на консалтинг и услуги с чеком от 200 000 ₽ — по методу «HH-партизан»:
вакансия на hh.ru → исследование компании → честное персональное касание в стиле собственника → встреча по скрипту → сделка.
Работает с телефона: система готовит касания, вы нажимаете «отправить».

## Что внутри
- **Сигналы HH** — вакансии топ-позиций (РОП, коммерческий директор, исполнительный), оценка 0–100, стоп-факторы (конкуренты, ниши без трафика, линейные роли, низкая зарплата).
- **Исследование** — сайт, страница команды (ЛПР), ЕГРЮЛ (DaData), публичный Telegram-канал собственника → факты с источниками и стиль его постов.
- **Касания** — 6 заходов, зеркалирование стиля (ты/вы, длина фраз, эмодзи), проверка качества и оценщик цифр (ничего не выдумывается). Claude — по желанию.
- **HH-переписка** — честный отклик, шаги как кандидат без слов-триггеров, перевод в Telegram/WhatsApp, слоты по Москве и вашему времени, дожим после встречи.
- **Конвейер** — одно касание на экране телефона, лимиты каналов против банов, капча hh — по ссылке, решаете вы.
- **Автопилот** — 08:00 фокус дня, 20:00 разбор и правило «нет ответа 3 дня = отказ», отчёт в Telegram.
- **Встречи и звонки** — персональный скрипт продающего интервью (рамка, SPIN, цифра-боль, тарифы, возражения до цены, закрытие выбором), разбор записей.
- **A/B заходов**, **аналитика и деньги** (₽ и $), **«Что даст 100»** с метками факт / норматив / допущение.
- **Кабинеты клиентов** (абонентка + кредиты), **мастер запуска**, **инвесторам** (наблюдатели), **безопасность** (2FA, шифрование секретов, журнал с хеш-цепочкой, зашифрованные бэкапы), **памятка с котиком** против мошенников.
- **CRM-мост** — импорт и экспорт таблицы `LEADMEET_CRM_лиды_HH.csv`, которую ведёт ваш агент.

## Быстрый старт
```bash
npm ci
cp .env.example .env      # минимум: BASE_URL, HOST
npm start                 # http://localhost:8787
DEMO_MODE=true npm start  # с демо-кабинетом и тестовой воронкой
npm test                  # тесты
npm run build:demo        # однофайловое демо в dist/
```
