# CLAUDE.md — память проекта LEADMEET OS

Читай этот файл перед любой задачей в репозитории. Здесь архитектура, команды, правила кода и запреты.

## Что это
Платформа привлечения собственников бизнеса (чек от 200 000 ₽) по методу «HH-партизан»:
вакансия на hh.ru как сигнал → исследование компании (сайт, страница команды, ЕГРЮЛ, Telegram-канал) →
персональное касание в стиле собственника → ответ → встреча по скрипту продающего интервью → разбор
записи → сделка. Плюс конвейер касаний для телефона, автопилот (утро/вечер), A/B заходов, экономика,
кабинеты клиентов (SaaS: абонентка + кредиты), безопасность.

Владелец продукта: Влад Лев (LEADMEET). Язык интерфейса, документов и коммитов-описаний — русский.

## Стек и принципы
- Node.js ≥ 22.5, **без фреймворков**: `node:http`, `node:sqlite`, `node:crypto`. Единственная рантайм-зависимость — `@anthropic-ai/sdk`; `esbuild` — только для сборки демо.
- Бизнес-логика — чистые ES-модули в `core/`, работают и на сервере, и в браузере (демо). Никаких импортов `node:*` в `core/`.
- Фронтенд — vanilla JS ES-модули в `web/`, без сборки (сервер отдаёт `/core/*` как есть).
- Деньги всегда парой: рубли и в скобках доллары (`money()`, `fmtMoney()`).

## Команды
- `npm start` — сервер на `PORT` (по умолчанию 8787). `DEMO_MODE=true` — демо-кабинет с тестовой воронкой.
- `npm test` — все тесты (должны быть зелёными перед коммитом).
- `npm run build:demo` — однофайловое демо в `dist/` (для Artifact и офлайн-показа).
- `npm run backup` / `npm run restore -- <файл.enc> <куда.db>` — зашифрованные бэкапы.

## Как добавить фичу
1. Логику — в `core/` (чистые функции), маршрут — `R('METHOD', '/path', 'perm', handler)` в `core/router.js` или `core/pipeline.js`.
2. Права: `perm` из `ROLES` в `core/catalog.js` (`area` — чтение и запись, `area:read` — только чтение, `null` — всем вошедшим).
3. Экран — функция `view*(el, param)` в `web/views-*.js`, регистрация в `VIEWS`/`NAV` в `web/app.js`; обучение — шаг в `web/tour.js` и `data-tour` на элементе.
4. Тест — в `tests/` (сценарий через `handle(ctx, ...)` с `MemStore` и `mockServices()`).
5. Пересобрать демо: `npm run build:demo`.

## Стиль кода
- ES-модули, `async/await`, именованные экспорты, без классов там, где хватает функций.
- Любой текст из базы или от пользователя в HTML — только через `esc()`; ссылки в `href` — только через `safeUrl()`.
- Регулярки по кириллице — `[а-яё]`, не `\w` (в JS `\w` не матчит кириллицу).
- Внешние данные (вебхуки, сайты) — обрезать (`clip`), проверять (`isEmail`, `safeUrl`), объекты — `sanitizeObject`.
- Комментарии — по-русски, коротко, «зачем», а не «что».

## Запреты (guardrails)
- **Не выдумывать факты** в касаниях: цифры только из карточки лида, кейсов (`settings.proofs`/`PROOFS`) и офферов. Оценщик (`unverifiedNumbers`) должен оставаться включённым.
- **Никаких техник обхода спам-фильтров, капчи и антибот-защит.** Капчу решает человек; отправка с личных аккаунтов — только вручную через конвейер; лимиты каналов не обходить.
- На hh.ru переписка — как у кандидата (без «система/кейсы/аудит/под ключ» и ссылок); формат работы обозначаем честно.
- Не коммитить персональные данные: реальные CRM-файлы, лиды, контакты, `data/`, `.env`. **Репозиторий публичный.** Демо-данные — только вымышленные (`core/mocks.js`).
- Не ослаблять безопасность ради удобства: CSRF, HttpOnly-cookie, scrypt, шифрование секретов, SSRF-защита в `server/services/web.js`, журнал целостности.
- Не удалять и не переписывать существующие тесты, чтобы «позеленить» сборку.
- Модель Claude по умолчанию — `claude-opus-5-5` (официальный SDK, адаптивное рассуждение, `fallbacks: 'default'`).

## Данные и окружение
- Все переменные — в `.env` (пример: `.env.example`). Мастер-ключ: `LEADMEET_MASTER_KEY` или `data/master.key` — хранить копию отдельно от бэкапов.
- Персональные данные граждан РФ — хранить на сервере в РФ (152-ФЗ), см. `docs/LEGAL.md`.
