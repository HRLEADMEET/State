## Из открытых агентных фреймворков (общие паттерны)
- **Оркестратор → исполнители → критик** (CrewAI, LangGraph, AutoGen): цепочка исследование → черновик → проверка качества → одобрение человеком.
- **Human-in-the-loop** (LangGraph interrupt): очередь одобрения — Конвейер.
- **Память проекта** (Claude Code, CLAUDE.md / context.md): `CLAUDE.md` и `settings` кабинета (оффер, кейсы, стиль, стоп-листы).
- **Инструменты с ограничениями**: каждое внешнее действие — через сервис с лимитами и журналом (hh, почта, Telegram, сайты).
- **Многоарендность**: кабинеты клиентов копируют «идеальную модель» владельца.
