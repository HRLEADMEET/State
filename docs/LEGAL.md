# Юридические рамки (кратко, не заменяет юриста)

## Персональные данные — 152-ФЗ
- Данные граждан РФ (ФИО, телефон, email собственников) **хранятся и первично обрабатываются на серверах в РФ** (ст. 18 ч. 5). Для продакшена — VPS в РФ (см. `SETUP.md`).
- Нужны: политика обработки ПДн на сайте, уведомление Роскомнадзора об обработке ПДн (pd.rkn.gov.ru), согласие в формах сайта (виджет — добавьте чекбокс и ссылку на политику).
- Только открытые источники: сайт компании, публичные страницы, ЕГРЮЛ, вакансия. Не покупаем «базы» с личными телефонами.
- По запросу человека — удалить данные (карточка лида → удалить; отписка срабатывает автоматически).

## Рассылки — 38-ФЗ «О рекламе», ст. 18
- Реклама по сетям электросвязи требует предварительного согласия. Персональное деловое письмо конкретному человеку по его вакансии обычно рекламой не считается, но: без массовости, с личным поводом, с возможностью отказаться.
- В каждом первом письме — фраза-отписка; заголовок List-Unsubscribe; отписка блокирует касания навсегда.
- Не используем чужие домены и подмену отправителя; свой домен с SPF/DKIM/DMARC.

## hh.ru
- Только официальный API (api.hh.ru) с зарегистрированным приложением и HH-User-Agent. Без парсинга страниц и обхода капчи.
- Переписка соискателя — по правилам площадки (п. 4.3.1: не превращать отклики в предложение услуг). Формат работы обозначаем честно.
- Лимиты и паузы: аккаунт уже банили за отклики без задержек.

## Мессенджеры
- Telegram/WhatsApp: только ручная отправка с личного аккаунта; без юзерботов и массовых рассылок незнакомым (нарушение правил площадок и бан).
- Массовые уведомления — через официальные API (Telegram Bot API, WhatsApp Business API) и только тем, кто написал первым.

## Договор и оплата
- Публичная оферта (ст. 435, 437 ГК РФ) уже есть — оплата по счёту/QR = акцепт.
- Предоплата 50%, акты по этапам, штрафы за просрочку оплаты — урок кейса с неоплатой 1 млн ₽.
