# Безопасность LEADMEET OS

## Что защищаем
Базу лидов и переписку (персональные данные), доступы к каналам (почта, hh, Telegram, Claude), деньги и кредиты, репутацию аккаунтов и домена, целостность цифр для инвесторов.

## Меры
| Угроза | Защита |
|---|---|
| Подбор пароля | scrypt, лимит 10 попыток / 15 мин с IP и 20 / час на email, одинаковое время ответа для существующих и несуществующих email, 2FA (TOTP) |
| Кража сессии | Случайный токен 256 бит, в базе — только хеш; HttpOnly + SameSite=Lax + Secure (на HTTPS); выход на всех устройствах; смена пароля завершает все сессии |
| CSRF | Каждый изменяющий запрос — заголовок `x-csrf`, совпадающий с токеном сессии |
| Подмена IP в заголовках | `X-Forwarded-For` учитывается только при `TRUST_PROXY=true` (за своим Caddy/Nginx), берётся последний адрес |
| XSS | Весь текст экранируется (`esc`), ссылки — только http(s) через `safeUrl`; CSP `script-src 'self'` блокирует инлайн-скрипты и `javascript:` |
| SSRF при исследовании сайтов | Только http/https и стандартные порты; IP проверяется в момент соединения (нельзя обойти DNS-подменой); запрет локальных, служебных и IPv4-mapped IPv6 диапазонов; каждый редирект проверяется; таймаут и лимит размера |
| Инъекции в почту | Адреса проверяются строго, CR/LF в заголовках запрещены, тема кодируется base64 |
| Загрязнение прототипа | Ключи `__proto__/constructor/prototype` вырезаются из любого входа, слияние с ограничением глубины |
| ReDoS | Ограничение длины входа для регулярок, ограниченные квантификаторы в email-шаблонах |
| Доступ к чужим данным | Каждый документ привязан к кабинету сессии; смена кабинета — только при членстве; роли владелец / менеджер / клиент / наблюдатель |
| Секреты каналов | AES-256-GCM мастер-ключом; в интерфейсе видны только последние 3 символа; менеджер и клиент их не видят |
| Тихие правки задним числом | Журнал действий с хеш-цепочкой (как блокчейн): изменение любой прошлой записи ломает проверку |
| Потеря данных | Зашифрованные бэкапы по расписанию с ротацией, ручной бэкап, экспорт JSON, восстановление скриптом |
| Бан аккаунтов и домена | Дневные лимиты по каналам, прогрев почты, рабочее окно и паузы, отписка в один клик, ручная отправка с личных аккаунтов, капча — человеку |
| Злоупотребление кредитами | Кабинеты клиентов ограничены тарифом, кредиты только переводом из баланса родителя |
| Падение процесса | Перехват неожиданных ошибок с логированием; в проде — автоперезапуск (Docker `restart: always` / systemd) |
