# Запуск LEADMEET OS

Три варианта: от «посмотреть сейчас» до «работать с клиентами завтра с телефона».

## 1. Посмотреть сразу — демо по ссылке
Демо-версия (Artifact) работает в браузере на телефоне и компьютере: вся логика, тестовая воронка, обучение.
Данные хранятся в вашем браузере, hh.ru и почта имитируются. Подходит, чтобы пройти путь и показать клиенту.

## 2. Работать завтра — на своём компьютере (15 минут)
1. Установите Node.js 22 LTS: https://nodejs.org (Windows/macOS — установщик).
2. Скачайте проект: `git clone https://github.com/HRLEADMEET/State.git && cd State && git checkout claude/consulting-client-acquisition-app-31enzc`.
3. `npm ci` → `cp .env.example .env` → в `.env` оставьте `BASE_URL=http://localhost:8787`, `HOST=127.0.0.1`.
4. `npm start` → откройте http://localhost:8787 → создайте кабинет владельца (первый пользователь — владелец).
5. Пройдите «Мастер запуска», подключите каналы (ниже), нажмите «Подготовить касания» — работайте из «Конвейера».

Телефон в той же сети Wi-Fi: `HOST=0.0.0.0` и адрес компьютера вида `http://192.168.x.x:8787`.

## 3. Постоянно и с телефона из любого места — VPS в РФ (1 час)
Персональные данные граждан РФ по 152-ФЗ храним на серверах в РФ: Timeweb Cloud, Selectel, Yandex Cloud, REG.RU (VPS от ~300 ₽/мес, 1 vCPU / 1 ГБ хватит).
1. Купите домен или поддомен (`leads.вашдомен.ru`), A-запись → IP сервера.
2. На сервере (Ubuntu 24.04): `curl -fsSL https://get.docker.com | sh`.
3. `git clone … && cd State && cp .env.example .env` — заполните `BASE_URL=https://leads.вашдомен.ru`, `LEADMEET_MASTER_KEY` (сгенерировать командой из `.env.example`), токены.
4. В `deploy/Caddyfile` замените домен. `docker compose up -d` — HTTPS настроится сам.
5. Копию `LEADMEET_MASTER_KEY` сохраните в менеджер паролей. Папку `data/backups` раз в неделю копируйте во внешнее хранилище (S3 / Яндекс Object Storage).

Без Docker: `deploy/leadmeet.service` (systemd) + любой обратный прокси с HTTPS.

## Подключения (раздел «Каналы»)
| Канал | Что сделать | Зачем |
|---|---|---|
| **hh.ru: поиск** | Зарегистрировать приложение на https://dev.hh.ru, указать `HH-User-Agent` вида `LeadmeetOS/1.0 (email)` | Сигналы: вакансии топ-позиций |
| **hh.ru: отклики** | В приложении dev.hh.ru получить OAuth-токен соискателя; ID резюме — из адреса резюме | Отклики и переписка из Конвейера; капчу hh решаете вы по ссылке |
| **Telegram-бот** | @BotFather → `/newbot` → токен; напишите боту, `chat_id` — из `https://api.telegram.org/bot<токен>/getUpdates` | Утренний фокус, вечерний итог, новые заявки и ответы |
| **Telegram (рабочий профиль)** | Ничего подключать не нужно: укажите @username. Отправка — из Конвейера: текст копируется, чат открывается, вы жмёте «Отправить» | Живые касания без ботов и банов |
| **Почта** | Свой домен + ящик на имя (Яндекс 360 / Mail.ru для бизнеса), SPF, DKIM, DMARC, пароль приложения | Письма собственникам с прогревом и лимитами |
| **WhatsApp / Zalo** | Номер телефона в карточке лида | Ссылка wa.me / zalo.me с готовым текстом |
| **Claude** | Ключ API на https://console.anthropic.com | Письма глубже под человека, разбор звонков |
| **ЕГРЮЛ (DaData)** | Бесплатный ключ на dadata.ru | Руководитель компании, дата регистрации, численность |
| **Записи звонков** | Whisper-совместимый сервис или Deepgram; или вебхук готовой расшифровки (Zoom, Телемост, МТС Линк, диктофон) | Разбор звонков, рост встреча → продажа |
| **Реклама и сайты** | Адрес вебхука из карточки канала → в лид-формы Директа, VK, TikTok, Meta, Zapier/Make; на сайт — код виджета | Заявки сразу в «Лиды» с utm |
| **Вход Google / Яндекс / VK** | OAuth-приложения, ключи в `.env`; redirect: `{BASE_URL}/api/auth/oauth/<provider>/callback` | Вход в один клик для клиентов |

## Первый день (чек-лист)
- [ ] Мастер запуска: оффер, 1–3 кейса с цифрами, кого ищем, 3–5 своих сообщений для стиля.
- [ ] Каналы: hh (поиск), Telegram-бот, рабочий Telegram (@username). Остальное — по мере готовности.
- [ ] Импорт CRM-файла агента (Сигналы HH → CRM-файл агента), чтобы не потерять текущие диалоги.
- [ ] «Подготовить ещё 20» в Конвейере → отправить с телефона → ответы вставлять в карточку лида.
- [ ] Включить автопилот (Настройки): утро 08:00, вечер 20:00 по вашему поясу.
