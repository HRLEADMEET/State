# Регламент дня и метод «HH-партизан»

## День (как в «агентной сети»: оркестратор утром и вечером)
| Время (ваше) | Что делает система | Что делаете вы |
|---|---|---|
| 08:00 | Автопилот: свежие вакансии hh → импорт → исследование (сайт, команда, ЕГРЮЛ, Telegram) → касания в Конвейер → фокус дня в Telegram | Открываете Конвейер на телефоне |
| Днём | Лимиты каналов, капча hh по ссылке, подсказки ответов | 60 касаний ≈ 1,5 ч: «скопировать → открыть → отправить»; ответы вставляете в карточку |
| Встречи | Персональный скрипт: рамка → факты → SPIN → цифра-боль → 2–3 тарифа → возражения до цены → закрытие выбором → оплата по QR в моменте | Ведёте встречу, отмечаете этапы, загружаете запись |
| 20:00 | Правило «нет ответа 3 дня = отказ», синхронизация hh, итог дня в Telegram | Отмечаете, что сделано |

## Метод HH-партизан (из ваших материалов)
1. **Сначала собственник напрямую.** Вакансия — повод. Ищем ЛПР: сайт → страница команды → ЕГРЮЛ → соцсети. Нашли контакт — пишем ему напрямую.
2. **Если нет — честный отклик на hh.** Формат обозначаем сразу (проектный руководитель, ИП). Переписка на hh — только вопросы кандидата: объём лидов, команда, кто проводит встречу.
3. **Нельзя на hh:** «система», «эксперт», «кейсы», «внедрю», «делегируете нам», «под ключ», «аудит», любые ссылки. Иначе бан по п. 4.3.1 соглашения. Приложение проверяет это автоматически.
4. **Ответили цифрами → переводим в Telegram/WhatsApp** (свой контакт не шлём, ждём их).
5. **В мессенджере:** качество лидов → если HR, честно: «не претендую на штат, нужен собственник на созвоне» → сколько ищут → аудит 20–30 минут с выбором из двух слотов.
6. **Фильтр:** от 100 лидов в месяц и задача усилить продажи. Ниши без трафика и линейные роли — отсев.
7. **Кодовое слово в вакансии** — ставим в начало отклика. Тест, анкета, ИИ-помощник hh — решение за вами.
8. **Капча hh** — решаете вы по ссылке из Конвейера. Никаких обходов.

## Цифры (факты из кейса и нормативы)
- Отклик → целевой лид: 2,7% (кейс). 100 откликов → 5 диалогов (норматив скрипта).
- 5 назначенных встреч в неделю, 3 доходят.
- Встреча → продажа: 14% → 28% после разбора 10 встреч.
- 50–80 откликов в день. Резюме поднимать каждые 4 часа.
- Ошибки, которые уже стоили денег: бан hh за отклики без пауз (лимиты и прогрев), неоплата 1 млн ₽ (оферта, предоплата 50%, акты по этапам).

## После встречи — дожим (4 касания)
День 0 вечером: цифра-боль + скрин воронки кейса + 2–3 кейса + видео. День 1 днём: «Ознакомились? Если формат не ваш — тоже нормально». День 1 вечером: ещё один кейс. День 3: мягкий релиз. Перед отправкой — проверить валюту и арифметику.

## Масштаб
Победивший заход из A/B → на новые ниши (IT, медицина, B2B-услуги, онлайн-школы). Клиенту, купившему систему, — свой кабинет: «Мастер запуска» с его оффером и кейсами, ваша модель копируется, кредиты переводятся из вашего баланса.
